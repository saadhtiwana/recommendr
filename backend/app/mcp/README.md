# mcp

The MCP server: Streamable HTTP transport with OAuth 2.1 authorization and per-org scoped tokens on the hosted instance, and stdio mode for self-hosters. Exposes the shared tools and read-only resources (project summaries, reports); spend tools require confirmation; rate-limited and audited. Later, the client side of the closed loop that publishes approved fixes. Phase 1: empty skeleton, no logic yet; other modules use it only through its service interface, never its tables.
