# billing

Keys, quotas and usage (no payments). Owns the BYOK key vault (envelope encryption: AES-256-GCM per-secret data keys wrapped by `KEY_ENCRYPTION_KEY`, `kek_version` for rotation; keys write-only, validated on save, revocable and replaceable, never logged), the credential resolver (org BYOK key, else the platform free-tier key within free limits, else blocked with a clear message), free-tier quotas, the global platform spend cap with pacing, budget reservations (authorize before each provider call, capture after) and the append-only usage ledger recording usage and cost per key and per org. Plans and entitlements are data rows, so paid plans could be added later without schema rewrites. The module keeps the name `billing` for that future. Phase 1: empty skeleton, no logic yet; other modules use it only through its service interface, never its tables.
